# 📚 Algoritmos e Programação - Lista de Exercícios VIII

Este repositório contém as soluções desenvolvidas para a **Lista de Exercícios VIII** da disciplina de **Programação de Soluções Computacionais**, ministrada pelo professor **Daniel Henrique Matos de Paiva** no **Centro Universitário UNA**.

---

## 🚀 Tecnologias Utilizadas

* 💻 **Linguagem:** Java
* 🛠️ **Ambiente:** VSCODE

---

## 📝 Exercícios Resolvidos

Abaixo está o resumo do que cada algoritmo implementado faz:

1. **🔢 Pirâmide de Números Repetidos:** Recebe um valor inteiro `n` e imprime uma estrutura de pirâmide onde cada linha `i` repete o número `i`, `i` vezes até a `n`-ésima linha.
2. **📈 Pirâmide de Números Crescentes:** Recebe um valor inteiro `n` e imprime uma estrutura de pirâmide contendo a sequência crescente de `1` até o número correspondente da linha atual.
3. **➕ Soma de Três Argumentos:** Função que recebe três parâmetros numéricos e retorna a soma exata deles.
4. **🔄 Verificador de Sinal (P/N):** Função com um argumento que retorna o caractere `'P'` caso o número fornecido seja positivo, ou `'N'` se for zero ou negativo.
5. **💰 Cálculo de Imposto sobre Vendas (somaImposto):** Função que atualiza o valor de custo de um produto aplicando a porcentagem da taxa de imposto sobre vendas informada.
6. **⏰ Conversor de Horário (24h para 12h):** Programa iterativo que converte e exibe horários do formato de 24 horas para o padrão de 12 horas (A.M./P.M.), rodando dentro de um loop de repetição controlado pelo usuário.

1. Clone este repositório na sua máquina local:
